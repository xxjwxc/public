# 2026-11-10

## public 库全面体检与修复（xxjwxc/public）

对 Go 工具库 `github.com/xxjwxc/public` 做了完整审查与修复，`go build` / `go vet` / `gofmt` / `go test -race` 全绿（仅剩 1 处 Windows API 必要的 unsafe.Pointer 提示）。

### 修复的高危 Bug
- **myqueue**：`TryPopTimeout` 每次调用起 goroutine 且 `popChan` 持锁向容量 1 的 channel 发送，导致死锁 + goroutine 永久泄漏（原测试跑 139s 超时）。整体重构 `sync.Cond` → 容量 1 的信号 channel，用 `select` + `time.Timer` 实现超时；Close 用 `close(chan)` 广播。API 未变。测试降至 1.4s。
- **weixin/oauth.go**、**myhttp/myhttp.go**：`body, err := ioutil.ReadAll(...)` 后 `if err != nil { return nil, e }` 返回了错变量（e 恒为 nil）→ 静默吞错。共 6 处。
- **weixin/mylog**：`Fatalf` 误传 `a...` 丢失格式串。
- **file.UploadFile**：所有分支只把 result 置 false 从不置 true（成功也返回失败）；无 O_TRUNC；错误后仍继续执行。
- **tools/rand.go**：全局共享 `*rand.Rand`（非并发安全），且 `rand.Seed(time.Now().Unix())` 用秒级种子导致同一秒返回值完全相同。改用 math/rand 顶层函数。
- **mymath.Gcd**：`Gcd(x, 0)` 整数除零 panic；float64 转换在超过 2^53 时丢精度。改整数实现。
- **fractional**：`Add/Sub` 会原地修改入参；`panic(fmt.Sprintf(...))` 无格式参数。
- **mycache**：`res.Data().([]byte)` 强制断言 panic；`encodeValue` 吞序列化错误；TryLock 的 check-then-act 非原子（改用 `NotFoundTable.NotFoundAdd`）。
- 格式串漏洞：`status.Errorf(code, m.Error)`、`fmt.Errorf(res.Errmsg)`、obs `doLog(level, fmt.Sprintf(...))` 双重格式化。
- **errors** 包（pkg/errors 旧版拷贝）：补 `Unwrap()`，使标准库 `errors.Is/As` 可穿透。
- **myredis**：`SET NX` 未命中返回 `redis.ErrNil` 与连接异常混淆，新增 `ErrLockFail`。
- **mylog**：包级 `_log` 变量改 `atomic.Pointer[myLog]` 消除 SetChange 与写日志的 race。
- **mydraw**：`os.Open` 错误被忽略。
- **wordsfilter**：测试已腐烂（断言与实现相反 + 依赖不存在的 `words_test.txt`），按真实语义重写。
- 统一为所有 HTTP 调用加超时（`myhttp.DefaultTimeout`、`weixin.DefaultTimeout`，默认 30s）。

### 验证结果
- `go build ./...` 通过；`go vet ./...` 仅剩 `clipboard_windows.go` 的 unsafe.Pointer（GlobalAlloc 内存，必要写法）
- `gofmt -l .` 为 0（原约 224 个文件不合规，其中 32 个是真实格式问题）
- `go test -race` 覆盖 errors/fractional/mymath/tools/mycache/myqueue/wordsfilter/mybigcamel/myreflect/snowflake/myswagger/sign 全通过

### 已知未修（留待决策）
- `myredis.Unlock(key)` 直接 `DEL`，不校验 value，存在"超时后误删他人锁"的经典问题；修复需改 API 签名为 `Unlock(key, value)`，属破坏性变更。
- `wordsfilter` 在 `StripSpace=false` 时，`Replace("你 他妈")` 完全不做替换（跨空格无法重新对齐），属算法缺陷。
- `mycache1/` 与 `mycache/` 包名重复（都叫 mycache），属历史遗留冗余模块。
- 仓库 `core.autocrlf=true`、index 存 LF，无需 `.gitattributes`；本地 gofmt 报错是工作区 CRLF 造成的假象。
